# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## V8 notes
- Root Directory for Vercel: `world-cup-app-v8-layout-confidence`
- Home page is fixtures-only.
- Confidence x2 is capped at 3 picks in local storage. A wrong confidence pick scores -5.
- Admin page is `/admin` and stores results/qualifiers locally until Firebase is connected.
