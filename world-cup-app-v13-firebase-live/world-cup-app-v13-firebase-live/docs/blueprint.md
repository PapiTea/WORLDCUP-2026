# **App Name**: PitchWizard 26

## Core Features:

- Social League Creation: Create and join private prediction pools via shareable invitation links powered by Supabase.
- Group Stage Selector: Interactive group grid to select the top 2 teams and best 3rd-place finishers for all 12 groups.
- Card-Based Match Prediction: Mobile-first score entry cards featuring flags, countdown timers, and locked states once kickoff begins.
- Sarcastic Match Recaps: An AI tool that generates personalized, humorous reactions based on your prediction accuracy versus the actual result.
- Knockout Bracket Engine: A dynamic tournament tree that unlocks as real-world results progress, allowing users to predict from Round of 32 through the Final.
- Confidence Boost Mechanic: Allow users to select one 'Confidence Pick' per round to act as a tool for doubling earned points on a high-stakes match.
- Global & Private Leaderboards: Real-time ranking system featuring point breakdowns and special achievement badges like 'Exact Score Wizard'.

## Style Guidelines:

- Primary color: Vibrant Stadium Indigo (#7C3AED), evoking the atmosphere of a night game under floodlights.
- Background color: Deep Midnight (#0C0912), a dark and modern canvas that lets team flags and card data pop.
- Accent color: Electric Blue (#2D67F6) for critical calls to action, such as submitting picks or locking 'Confidence' matches.
- Font pairing: 'Space Grotesk' for technical-looking headlines and statistics, with 'Inter' used for all UI text and long-form leaderboard lists.
- Crisp, flat flag icons paired with thick-stroke outline icons for sport-specific metrics (whistles, goals, timers).
- Mobile-first stack layout utilizing rounded 'cards' to manage information dense data on small screens.
- Smooth CSS transitions for card expansion and 'pulse' animations for active live-score updates.
